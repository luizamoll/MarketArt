# MarketArt

**Marketplace acadêmico de arte · Projeto em desenvolvimento**

MarketArt é um projeto web desenvolvido para a faculdade com a proposta de aproximar artistas, designers e pessoas interessadas em descobrir, publicar, comprar e vender trabalhos artísticos.

> A ideia ainda está em fase de definição acadêmica. Este repositório registra a evolução real do projeto conforme os requisitos forem amadurecendo durante a disciplina.

## Conceito inicial

A plataforma é pensada como um marketplace de arte no qual diferentes tipos de trabalhos podem ser apresentados e comercializados, incluindo pinturas, ilustrações, artes digitais e pacotes de design.

Dois perfis orientam a experiência inicial:

- **Artista / criador:** poderá apresentar seu trabalho, construir um perfil e publicar artes ou pacotes.
- **Cliente / comprador:** poderá explorar trabalhos, conhecer artistas e visualizar itens disponíveis.

Funcionalidades como autenticação, carrinho, pagamento e persistência de dados só serão indicadas como implementadas quando realmente fizerem parte do projeto.

## Escopo inicial

As primeiras telas consideradas para o projeto são:

- Página inicial
- Exploração de artes
- Detalhes de uma obra ou produto
- Perfil do artista
- Cadastro e login
- Publicação de arte

O escopo poderá mudar de acordo com as orientações da disciplina.
