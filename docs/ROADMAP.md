# Roadmap do MarketArt

Este roadmap acompanha a evolução real do trabalho. Itens planejados não devem ser marcados como concluídos antes de existirem no projeto.

## Etapa 2 — Páginas principais

- [ ] Página de exploração de artes
- [ ] Página de detalhes de uma obra ou produto
- [ ] Perfil de artista
- [ ] Tela de cadastro / login
- [ ] Tela de publicação de arte

## Etapa 3 — Interações

Dependendo dos requisitos da disciplina:

- [ ] Busca ou filtro de trabalhos
- [ ] Validação de formulários
- [ ] Interações de interface com JavaScript
- [ ] Favoritos ou carrinho simulados, se fizerem sentido para a entrega

## Etapa 4 — Evolução opcional

Somente se o projeto crescer além da entrega acadêmica:

- persistência de dados;
- autenticação real;
- API / back-end;
- banco de dados;
- integração de compra ou pagamento;
- testes automatizados;
- publicação de uma versão de demonstração.

## Regra do projeto

O MarketArt deve crescer conforme os requisitos e o aprendizado avançarem, sem adicionar complexidade apenas para preencher portfólio.
