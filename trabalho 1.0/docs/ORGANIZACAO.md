# Organização do MarketArt

Esta pasta registra a estrutura combinada para o trabalho acadêmico.

## Estrutura

```text
trabalho 1.0/
├── index.html
├── pages/
│   ├── cadastro.html
│   ├── carrinho.html
│   ├── configuracoes.html
│   ├── categorias.html
│   ├── pesquisa.html
│   ├── checkout.html
│   └── notificacoes.html
├── css/
│   └── style.css
├── javascript/
│   └── script.js
├── img/
│   ├── produtos/
│   ├── perfis/
│   └── interface/
└── docs/
    └── ORGANIZACAO.md
```

## Divisão das páginas

### Luiza
- `index.html` — página inicial
- `pages/cadastro.html` — cadastro / compra e venda
- `pages/carrinho.html` — carrinho
- `pages/configuracoes.html` — configurações

### Kaiser7009
- `pages/categorias.html` — categorias
- `pages/pesquisa.html` — pesquisa
- `pages/checkout.html` — finalização da compra
- `pages/notificacoes.html` — notificações

## Regra de organização

- HTML das páginas fica em `pages/`, com exceção da página inicial, que permanece como `index.html`.
- Estilos ficam em `css/`.
- JavaScript fica em `javascript/`.
- Imagens são separadas por finalidade em `img/`.
- Documentação do trabalho fica em `docs/`.
- Cada integrante deve priorizar os arquivos sob sua responsabilidade para reduzir conflitos durante o desenvolvimento.
